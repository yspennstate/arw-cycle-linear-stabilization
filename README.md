# Linear stabilization of subcritical activated random walk on the cycle

Yitzchak Shmalo

Consider activated random walk on the cycle Z_n with symmetric nearest-neighbour jumps and sleep rate lambda > 0,
started from independent Poisson or Bernoulli particle counts of mean zeta, all particles active. If zeta is below
the critical density rho_c(lambda), then the total number of topplings needed to stabilize the system is of order n
with probability tending to one. Previously a bound of order n log^2 n was known in this range for a fixed number of
particles, from the work of Hoffman, Johnson and Junge. As a consequence the odometer at a fixed site is tight. The
proof combines the stable odometers built by Johnson and Richey for the subcritical odometer tail on Z with a pasting
argument on the cycle and a routing of Poisson particles onto Bernoulli sites.
